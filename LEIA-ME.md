# Sistema de Apuração Eleitoral — Guia do Administrador

Bem-vindo ao seu painel de gestão de pesquisas eleitorais. Este sistema foi estruturado para garantir total isolamento de dados, segurança nas coletas de campo e agilidade na apuração dos resultados.

---

## 1. Primeiros Passos
* **Acesso Master:** Ao acessar o sistema pela primeira vez com o banco zerado, clique em **Administrador** e escolha a opção **"Criar Administrador Master"** para registrar sua conta principal.
* **Segurança:** O painel administrativo é protegido por autenticação segura. Nunca compartilhe sua senha de Administrador Master.

## 2. Gestão de Entrevistadores (Equipe de Campo)
Para cadastrar novos entrevistadores e permitir que eles coletem dados:
1. Acesse o painel administrativo e vá na aba **"Gerenciar Equipe"**.
2. Cadastre o nome do entrevistador. O sistema gerará um **código de acesso único** (ex: `ENT-XXXX`).
3. Repasse o código individual apenas para o respectivo entrevistador. No campo, ele selecionará o próprio nome e digitará esse código de forma sigilosa para liberar a coleta.
4. *Atenção:* Os códigos de acesso funcionam como senhas de campo. Nunca exiba ou publique a lista de códigos publicamente.

## 3. Coleta de Dados (Entrevistadores)
* O entrevistador deve acessar a tela inicial, selecionar o perfil **"Entrevistador"**, buscar o próprio nome na lista e digitar o código de acesso.
* Cada formulário preenchido é enviado instantaneamente e de forma segura para o banco de dados exclusivo desta instância.

## 4. Acompanhamento e Relatórios
No painel de apuração, você conta com ferramentas completas:
* **Visão Geral e Gráficos:** Acompanhe o percentual de conclusão da meta de entrevistas, bairros cobertos e estatísticas divididas por localidade.
* **Opinião e Candidatos:** Visualize os resultados consolidados em tempo real.
* **Exportação:** Utilize o botão **"Exportar CSV"** no topo do painel sempre que precisar baixar os dados brutos para análises externas no Excel ou Google Sheets.
* **Impressão:** O botão **"Imprimir"** formata automaticamente o relatório gerencial para PDF ou papel.
